## OBS-028 — Derivative authority may live on mutable surfaces (goal strings on issues)
**Relationship:** supports PHI-034

On 2026-07-05, rts-proto moved its /goal strings from a reviewed markdown file (AGENT_KICKOFF.md) onto the graduating GitHub issue's body (## Goal fenced section, PR #10), making the issue a complete run ticket for an eventual Switchboard-style worker. The mutability risk of an unreviewed surface was explicitly priced and accepted on one condition: every mechanical claim in a goal string is enforced by committed checks (known-failing contracts, golden guards, the gates loop), so editing the issue can reword the evaluator's phrasing but cannot weaken the gate. Placement rule derived: a document whose authority is derivative (all load-bearing claims enforced elsewhere at reviewed altitude) may live on a mutable low-friction surface; only original authority requires the reviewed surface. Contrast case: Switchboard's merge-#23 sequencing lived as prose-only authority in a task prompt and failed exactly as prose coordination predicts (2026-07-03).
