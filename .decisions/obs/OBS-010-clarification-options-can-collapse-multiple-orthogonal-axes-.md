**Status:** active

Clarification options can collapse multiple orthogonal axes into a single false choice. When presenting "Option C" as a single bundled thing, that option may actually conflate two independent decisions (e.g., trigger mechanism vs. execution context) — picking it forces an unintended bundle. The fix when caught: separate the axes and ask each independently rather than rationalizing the bundle. Useful diagnostic during clarification, RFC, or design-doc processes — if a respondent says "I like A but C goes somewhere different," that is a signal of axis collapse, not indecision. Observed in Claude-Root spec 010-autonomous-workflow Q1: trigger mechanism (A: slash command) and execution context (separate question entirely) were collapsed into Option C. User caught it; restructured into two questions.
