# Oracle Index

One line per record. Format:
`ID | status | domain | one-sentence hook`

This file is the retrieval surface — `/oracle` reads it to pick which records
to open. Keep hooks specific enough that relevance is judgeable from this line
alone. Update the relevant line in the same PR as any record change.
